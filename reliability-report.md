# Исправления по test.rar — WinSetup 1.1.2
Дата: 14.10.2026. Выполнено локально, без публикации.

## Что исправлено
- После успешного завершения установщика результат проверяется до шести раз с паузами 2 секунды. Команда winget list ограничена 20 секундами, чтение через PowerShell — 10 секундами на вызов. Отмена проверяется между вызовами и во время пауз.
- Для Discord, Claude и Armoury Crate дополнительно читаются записи Uninstall: точное имя, известный издатель, при закреплении — точная версия. Совпадение части идентификатора или версии не считается успехом.
- Vencord проверяется по модификации последнего стабильного Discord: файл app.asar должен ссылаться на существующий непустой dist/patcher.js, рядом должен быть _app.asar. Одних скачанных файлов Vencord недостаточно. Каталоги выбираются по числовой версии app-*; поддерживаются переменные каталога данных, используемые установщиком.
- Успех процесса без подтверждения результата получает отдельный статус needs_verification («Нужна проверка»). До запуска установщика на диск сохраняется verification_only. После прерывания или неопределённого результата продолжение выполняет проверку без повторной установки. Из старых журналов распознаётся сообщение «Код успеха=true; постпроверка не нашла программу».
- Ненулевой код неизвестной ошибки установщика больше не объявляется автоматически временным. Повтор допускается для распознанной сетевой ошибки/занятого установщика. Код процесса сохраняется в десятичном и шестнадцатеричном виде; исходный код внутреннего установщика остаётся в конце вывода.
- Финальная проверка может подтвердить поздно обнаруженную установку. Ошибка чтения состояния отличается от отсутствия программы; реальная ошибка установщика не скрывается одним фактом обнаружения приложения.
- Ошибки PowerShell выводятся как текст UTF-8 вместо CLIXML. ServiceDisabled при создании точки объясняется на русском. Службы не включаются, защита системы и подтверждение продолжения без точки не обходятся.
- Длинный вывод установщиков сокращается с сохранением начала и конца; ANSI-последовательности удаляются. Поэтому лицензия NVIDIA не вытесняет конечный код ошибки.
- Таблица задач обновляется при получении нового состояния. Подробности сворачиваются, открытые строки сохраняются; сообщения экранируются. Полный проход с ошибками обозначается как завершённый с замечаниями. Убрано неподтверждённое напоминание именно про AMD B550.
- Батка публикации теперь требует также прохождения тестов интерфейса; батка исходников включает этот отчёт.

## Допущения и остающиеся ограничения
Это исправление обнаруженных дефектов, а не гарантия отсутствия всех ошибок.
Реальная установка на чистой Windows и проверки реальных программ после установки не выполнялись. WinSetup.exe, установщики, скачивание пакетов, твики, удаления Appx и действия со службами на этом ПК не запускались. Рабочий winsetup.toml, vault.rs, настройки и данные пользователя не менялись.
Код NVIDIA 0xE6000000 из архива не раскрывает причины отказа: исправлено поведение WinSetup, но не заявлено, что устранена проблема самого установщика/драйвера/оборудования.
У Armoury Crate завершение вспомогательного установщика может не означать готовность приложения. Без достоверного обнаружения остаётся «Нужна проверка».
Для Vencord поддерживается стабильная стандартная установка Discord. Версию установщика Vencord нельзя приравнивать к версии модификации; закреплённая версия требует отдельной проверки и не объявляется подтверждённой.
Неизвестные формы таблицы winget, изменённые издателем имена регистрации или неподдерживаемая раскладка файлов дают явную неопределённость вместо ложного успеха.
Ограничены по времени команды чтения. Работающие установщики не убиваются принудительно; отмена установки профиля действует между задачами. Признак до запуска защищает от автоматического повторного запуска при аварии, но не обеспечивает транзакционный откат установки.
GitHub и релиз 1.1.1 не обновлялись. Новый EXE — release/WinSetup.exe (1.1.2).
