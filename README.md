# WinSetup

Приложение для настройки Windows на Tauri 2: Rust, TypeScript и HTML/CSS.

В проекте есть профили настройки, управление программами и автозапуском, твики Windows, резервные копии Vault и раздел диагностики для разработчика.

## Сборка в Windows

Нужны Node.js с npm, Rust с MSVC и Visual Studio Build Tools с компонентами C++ и Windows SDK.

Запустите `build.bat`. Скрипт установит зависимости интерфейса при необходимости, соберёт UI и Rust-приложение и поместит результат в `release/WinSetup.exe`. Если рабочего конфига ещё нет, рядом с EXE будет создана копия `winsetup.example.toml`.

## Проверки

Из корня проекта:

```powershell
npm run build
cd src-tauri
cargo check
cargo test --lib
```

Включение `application.dev_mode` добавляет раздел «Тесты». Реальные обратимые тесты запускаются отдельно с подтверждением. Перед изменениями сохраняются снимки отката; незавершённый откат требует восстановления сохранённых значений.

## Содержимое репозитория

- `src-tauri/src/` — Rust-приложение и тесты.
- `ui/` — исходники интерфейса; `dist/` — собранный интерфейс.
- `winsetup.example.toml` — пример конфигурации без пользовательских настроек.

Рабочий `winsetup.toml`, журналы, резервные архивы, зависимости и локальные EXE в репозиторий не включаются.
## Публикация на GitHub

- `publish-files.bat` — отправить исходники, собранный интерфейс и отчёт bootstrap в `main`. Рабочие конфиги, EXE, журналы, архивы и зависимости исключены. Force push не применяется.
- `publish-release.bat` — собрать интерфейс, выполнить cargo check и unit-тесты, собрать EXE, отправить исходники и опубликовать GitHub Release с `WinSetup.exe`. Размер и SHA-256 файла проверяются по ответу GitHub. Программа не запускается. Конфиги не прикрепляются.

Для следующей версии измените только `version` в `src-tauri/tauri.conf.json`, например на `1.1.1`, и запустите батку релиза. Версии Cargo/npm и lock-файлы синхронизируются при сборке. Опубликованный релиз не перезаписывается; незавершённый черновик можно продолжить повторным запуском. Аргумент `nopause` убирает ожидание клавиши в конце.

Нужны Git for Windows с авторизацией GitHub в Git Credential Manager, npm и Rust/MSVC. GitHub CLI не требуется. Батки рассчитаны на `main` и `origin = https://github.com/TheMorgxx/WinSetup.exe`. Если удалённая ветка изменилась независимо, сначала согласуйте её с локальной. Пароли и токены не записываются в батки или файлы проекта.
