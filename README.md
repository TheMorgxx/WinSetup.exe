# WinSetup

Приложение для настройки Windows на Tauri 2: Rust, TypeScript и HTML/CSS.

В проекте есть профили настройки, управление программами и автозапуском, твики Windows, резервные копии Vault и раздел диагностики для разработчика.

## Сборка в Windows

Нужны Node.js с npm, Rust с MSVC и Visual Studio Build Tools с компонентами C++ и Windows SDK.

Запустите `build.bat`. Скрипт установит зависимости интерфейса при необходимости, соберёт UI и Rust-приложение и поместит результат в `release/WinSetup.exe`. Если рабочего конфига ещё нет, рядом с EXE будет создана копия `winsetup.example.toml`.

## Проверки

Из корня проекта:

```powershell
npm run build
cd src-tauri
cargo check
cargo test --lib
```

Включение `application.dev_mode` добавляет раздел «Тесты». Реальные обратимые тесты запускаются отдельно с подтверждением. Перед изменениями сохраняются снимки отката; незавершённый откат требует восстановления сохранённых значений.

## Содержимое репозитория

- `src-tauri/src/` — Rust-приложение и тесты.
- `ui/` — исходники интерфейса; `dist/` — собранный интерфейс.
- `winsetup.example.toml` — пример конфигурации без пользовательских настроек.

Рабочий `winsetup.toml`, журналы, резервные архивы, зависимости и локальные EXE в репозиторий не включаются.
