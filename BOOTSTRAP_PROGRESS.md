# Подготовка среды — прогресс

## Этап 1 — модуль проверок и конфиг готовы
Добавлен bootstrap.rs: единый результат проверок, безопасное создание отсутствующего конфига через persist_noclobber, встроенные профили и выбор D: либо системного диска. Существующий файл, включая невалидный, не перезаписывается. winget проверяется вызовом --version по PATH и WindowsApps; интернет — только локальный признак Connectivity=4. Права и место только читаются. Добавлен тест конфигурации.
Осталось: подключение блока готовности/предпросмотра, установка winget с проверкой подписи, обработка ожидающих задач, проверки и итоговый отчёт.
## Этап 1 — подключение готово
Главная и предпросмотр показывают единый блок проверок; при первом запуске уведомление о создании конфига. Обработка ошибки чтения конфига позволяет проверить среду и создать только отсутствующий файл. Предпросмотр не скачивает пакеты.

## Этап 2 — реализация готова, идут проверки
Установка по подтверждению: пакет v1.29.380 и архив зависимостей из Microsoft/winget-cli, UI.Xaml 2.8.6 из Microsoft/microsoft-ui-xaml. Зафиксированы SHA-256 официальных файлов. HTTPS, тайм-аут, лимит размера, не более трёх редиректов по белому списку; из ZIP извлекаются только VCLibs x64 с лимитом распаковки. Перед Add-AppxPackage проверяется подпись каждого устанавливаемого файла и Microsoft Corporation. Временная папка отдельного запуска очищается при успехе, ошибке и обработанной панике.
Добавлены отдельная кнопка установки, согласие в общем подтверждении профиля, одно диалоговое сообщение Store за сессию и «Проверить снова». Задачи winget/msstore получают waiting_winget и не запускают установщики, постпроверка их не считает ошибками. При продолжении подготовка выполняется снова.
В devtest добавлена одна безопасная проверка конфиг/winget; существующий match порядка этапов дополнен новым Action::Bootstrap для компиляции. Системные операции при разработке не запускались.
